# Nome do projeto: Projeto sprint 4 (projeto coffe shop)

## Descrição do projeto:

Projeto realizado durante a sprint 4 do bootcamp da tripleten , as tecnologias usadas foram html,java,css, 


# Funcionalidades: 

Ao clicar em Receitas o mesmo será levado para proxima página que contém receita chamada aeropress e a receita de prensa francesa.

Ao clicar em Reservas será direcionado para uma página que precisa adicionar seu nome,e-mail,data,hora e numero de convidados ,concordar com os termos e clicar no botão re reserva.
